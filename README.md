# 海洋漂流瓶 v0.2

这是一个手机优先的静态网页原型，用来验证“向黄昏海岸倾诉、把话装进漂流瓶、日后在情绪潮汐里回望、也从远方捡到一点温柔”的核心体验。

## 如何打开

直接用浏览器打开：

`/Users/xiaocong/Desktop/海洋漂流瓶/index.html`

这个版本不需要安装依赖、不需要账号，也没有后端服务。

## 当前功能

- 威海黄昏灯塔海岸主视觉
- 写给海的话
- 捡一只预设漂流瓶
- 用一句温柔回应点亮灯塔
- 选择轻量心情标签
- 投出漂流瓶动画
- 情绪潮汐本地回望
- 海浪白噪音开关
- `localStorage` 本地保存
- 空内容拦截
- 强烈危险信号的温柔提示

## 产品语气

- 海接住倾诉
- 瓶子带走烦恼
- 灯塔替陌生人守望
- 不做热闹社区感，不做点赞、排行或头像墙

## 当前边界

- “捡一只漂流瓶”暂时使用预设来信，不来自真实用户
- 回应不会上传，也不会公开
- 后续做真实陌生人互动前，需要先设计审核、举报、求助和隐私机制

## 后续方向

- 加入真实威海取景素材或手绘视觉资产
- 将“捡瓶子”和“点亮灯塔”升级为安全的匿名回应系统
- 增加情绪潮汐的时间线、月度回望和海域地图
- 设计隐私、审核、求助入口和内容安全机制
- 评估是否包装成移动端 App
