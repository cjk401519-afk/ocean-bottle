# 海洋漂流瓶 v0.4

这是一个手机优先的静态网页原型，用来验证“向黄昏海岸倾诉、把话装进漂流瓶、日后在情绪潮汐里回望、也从远方捡到一点温柔”的核心体验。v0.4 重点把它推进到可以邀请朋友试用的内测状态。

## 如何打开

直接用浏览器打开：

`/Users/xiaocong/Desktop/海洋漂流瓶/index.html`

这个版本不需要安装依赖、不需要账号，也没有后端服务。

线上地址：

`https://cjk401519-afk.github.io/ocean-bottle/`

## 当前功能

- 威海黄昏灯塔海岸主视觉
- 写给海的话
- 远方回声：等待预设漂流瓶靠近、打开来信、送出回应
- 用一句温柔回应点亮灯塔，把光送回远方
- 收藏捡到的温柔来信到情绪潮汐
- 首次打开的三步轻引导
- 邀请朋友试用：复制链接、系统分享
- 反馈入口：复制反馈文案、打开 GitHub 反馈页
- PWA 基础支持：manifest、service worker、桌面图标
- 选择轻量心情标签
- 投出漂流瓶动画
- 情绪潮汐本地回望
- 打开单只漂流瓶查看完整内容
- 给过去的自己留一封本地回信
- 真实海浪白噪音开关
- `localStorage` 本地保存
- 空内容拦截
- 强烈危险信号的温柔提示

## 当前边界

- “捡一只漂流瓶”暂时使用预设来信，不来自真实用户
- 回应不会上传，也不会公开
- 情绪潮汐详情和给自己的回信都只保存在当前设备
- “收藏这束光”只把预设来信保存到当前设备，不会同步到云端
- “添加到桌面”受不同手机浏览器限制，不能保证每台设备都出现原生安装弹窗
- 后续做真实陌生人互动前，需要先设计审核、举报、求助和隐私机制
