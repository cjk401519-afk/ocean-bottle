# 海洋漂流瓶 v0.1

这是一个手机优先的静态网页原型，用来验证“向黄昏海岸倾诉、把话装进漂流瓶、日后在情绪潮汐里回望”的核心体验。

## 如何打开

发布后可通过 GitHub Pages 打开；本地也可以直接用浏览器打开 `index.html`。

这个版本不需要安装依赖、不需要账号，也没有后端服务。

## 当前功能

- 威海黄昏灯塔海岸主视觉
- 写给海的话
- 选择轻量心情标签
- 投出漂流瓶动画
- 情绪潮汐本地回望
- `localStorage` 本地保存
- 空内容拦截
- 强烈危险信号的温柔提示

## 产品语气

- 海接住倾诉
- 瓶子带走烦恼
- 灯塔替陌生人守望
- 不做热闹社区感，不做点赞、排行或头像墙
